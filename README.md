# 🚀 CodeQuest

CodeQuest is a modern coding and aptitude preparation platform inspired by LeetCode. It helps students practice coding questions, aptitude tests, and track their learning progress through a clean and responsive interface.

---

## ✨ Features

- 🔐 User Authentication
- 💻 Coding Questions
- 🧠 Aptitude Practice
- 📊 Progress Tracking
- 📱 Responsive Design
- 🌙 Dark/Light Mode
- Admin Dashboard
- Secure Backend API

---

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/CodeQuest.git
```

### Go into project

```bash
cd CodeQuest
```

### Install Frontend

```bash
cd client
npm install
npm run dev
```

### Install Backend

```bash
cd ../server
npm install
npm run dev
```

---

## Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=5001
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
